Using The Data

What to know before you analyse.

Before You Start.

  • No Daily Totals In The File.

    Build them from the episodes with timealloc.

  • Episodes Differ By Design.

    Redefine them with epigenx before comparing.

  • Minute 0 Is Not Midnight.

    Diary days start at different times: use svystart.

  • Surveys Are Not One Sample.

    Estimate within each survey, then combine.

The full guidance, with worked examples in Stata (and later R), will be in the guide How to Work with MTUS+ Data.

More details will be provided with the new release.
